.. _gui:

Graphical User Interface (GUI)
==============================

Paidiverpy provides a browser-based dashboard for building, validating and
running image-processing pipelines without writing Python code.

Installation and launch
-----------------------

Install the optional GUI dependencies and launch the dashboard:

.. code-block:: bash

    pip install "paidiverpy[gui]"
    paidiverpy --gui

The dashboard is available at ``http://127.0.0.1:8792`` by default. The bind
address, port and development reload mode can be changed with:

.. code-block:: bash

    paidiverpy --gui --host 0.0.0.0 --port 8792 --reload

Use ``paidiverpy --help`` for the complete command-line reference. Saved
configurations and run outputs are stored under ``~/Documents/paidiverpy/``.

Pipeline builder
----------------

The visual builder exposes general settings, loading-time sampling and
conversion, all built-in processing modes and custom algorithm steps. Changes
are synchronized with the editable YAML representation. Selecting YAML scrolls
to its corresponding form, while focusing a form field selects its YAML lines.

The **Demos** tab provides grouped workflows for benthic, plankton, iFDO, raw
and NEF images, sampling, parallel processing and custom algorithms. Bundled
sample datasets download automatically and are cached locally.

Running and inspecting results
------------------------------

During execution, step cards show pending, running, completed and failed states
with timings. The Log view streams pipeline messages and reports current and
peak RAM, retained xarray size and elapsed time.

The **Images** tab renders bounded previews directly from retained xarray steps.
When ``track_changes`` is enabled, users can inspect every retained stage and
compare one final-output image across the pipeline. **Save images** exports the
full-resolution output of the selected step.

The **Metadata** tab displays the processed image metadata as a Pandas HTML
table. The **Summary** tab provides the pipeline overview and a collapsible
investigation section for diagnostic plots generated by test-mode steps.
