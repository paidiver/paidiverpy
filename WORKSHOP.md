# Pre-event

This page contains all the pre-event setup required to prepare you to make the most of the workshop.

## Run the codes

To run the codes for this workshop, we have prepared a ready to use environment for you to use. In this case, we will not to care about installing dependencies or download example datasets. Everything is already configured and ready for you to use.

The environment were create in "notebook servers".  A notebook server is a computer program that runs in the background and allows users to create, edit, and run interactive documents called notebooks. These notebooks can contain text, code, equations, and visualizations, making them useful for data analysis, research, and programming. The server provides a web-based interface where users can write and execute code in languages like Python. One popular example is Jupyter Notebook, which enables users to run code in small sections, see the results immediately, and document their work in an organized way. In our case, we will be using a **remote notebook server**, meaning the code will not run on your own computer but on a powerful server elsewhere. This allows for faster processing, access to specialized resources, and the ability to work from anywhere with an internet connection.

For this workshop, we are going to work with two remote services: the NOC's Data Science Platform (DSP) and JASMIN.
